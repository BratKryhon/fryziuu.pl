FRIZIUU SCANNER
DARMOWY SKANER WINDOWS

Sprawdź ślady modyfikacji Minecrafta.

Darmowy, lokalny skaner artefaktów Minecraft Java. Uruchamiasz go na komputerze, widzisz przebieg w oknie CMD, a po skanowaniu otrzymujesz raport HTML.

Jak uruchomić?

01
Pobierz i rozpakuj

Rozpakuj ZIP w wybranym folderze.

02
Włącz Minecraft

Pozostaw uruchomioną grę Java Edition.

03
Uruchom CMD

Kliknij dwukrotnie Uruchom-skaner.cmd. Wynik otworzy się automatycznie.

Co program sprawdza?

  • Procesy Java i dostępne argumenty uruchomienia JVM.
  • Katalog aktywnej instancji Minecrafta, gdy da się go ustalić.
  • Nazwy plików JAR w folderach instancji, mods i libraries.
  • Wybrane artefakty i nazwy kojarzone ze znanymi klientami.
  • Dostępne moduły procesu, jeśli Windows pozwala je odczytać.
  • Log gry, z którego może odczytać nick i wersję.

Jak rozumieć werdykt?

BRAK WYKRYTYCH WSKAŹNIKÓW – skaner nie znalazł pasujących artefaktów.

NIEJEDNOZNACZNY – znaleziono słabe wskaźniki wymagające sprawdzenia.

PODEJRZANY – znaleziono co najmniej dwa wskaźniki średniej wagi.

SKAN NIEPEŁNY – nie udało się wykryć uruchomionego Minecrafta.

Bezpieczeństwo i kod

Program jest otwartym skryptem PowerShell. Działa tylko do odczytu: nie usuwa plików, nie modyfikuje Minecrafta, nie wyłącza Defendera i nie wysyła raportu do internetu. Nie potrzebuje uprawnień administratora do podstawowych kontroli. Administrator nie daje 100% dokładności.

Pobierz i przejrzyj cały kod źródłowy

Pokaż fragment kodu skanera
Get-CimInstance Win32_Process |
  Where-Object {
    $_.Name -in @('javaw.exe','java.exe') -and
    $_.CommandLine -match 'minecraft|fabric|forge'
  }

Ważne ograniczenia

Nie istnieje uczciwa gwarancja wykrycia każdego cheata ani 90% wszystkich injectorów. Klient może być zmieniony, zaciemniony, uruchomiony z innej lokalizacji lub działać wyłącznie w pamięci. Ten skaner nie potwierdza, że kod został wstrzyknięty do procesu. Nazwa klienta zostanie podana tylko wtedy, gdy istnieje czytelny wskaźnik; w innym przypadku wyświetli „Nieustalony”.

Nie używaj wyniku jako jedynej podstawy bana. Skanowanie komputera innej osoby wymaga jej zgody.
